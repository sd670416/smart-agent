# 系统时间与模型联网搜索设计

## 1. 目标

为智能助手增加两项只读能力：

1. `system.current_time`：读取 Agent 服务器指定时区的当前日期和时间，并为“今天、本月、今年、最近 N 天”等相对时间查询提供确定基准。
2. `web.search`：查询公开互联网信息，并在 OpenAI 与智谱模型之间切换时自动选择对应供应商的原生联网能力。

现有项目、合同等内部业务查询继续走 smart-boot，制度与企业文档继续走知识库。联网能力不得绕过菜单、按钮和数据权限，也不得把内部数据发送到外部模型或搜索服务。

## 2. 总体架构

Agent 对编排层暴露统一工具：

```text
用户问题
  -> 能力路由
     -> system.current_time -> 本地系统时钟
     -> project.*          -> smart-boot 业务接口
     -> knowledge.search   -> 企业知识库
     -> web.search         -> WebSearchProvider
                              |- OpenAIWebSearchProvider
                              `- ZhipuWebSearchProvider
```

`web.search` 的输入输出协议由 Agent 定义，不把供应商协议暴露给聊天编排、前端或业务系统。模型供应商切换时只切换 Provider，实现层负责转换请求、响应、引用和错误。

## 3. 能力路由规则

### 3.1 系统时间

以下问题调用 `system.current_time`，不联网：

- 当前日期、当前时间、星期、时区；
- 今天、昨天、明天、本周、本月、本季度、今年；
- 最近 N 天、未来 N 天等相对时间口径。

涉及业务数据时，模型先取得时间基准，再调用对应业务工具。例如“查询今年立项的项目”先解析今年起止日期，再调用 `project.query`。

### 3.2 联网搜索

`web.search` 是通用公开互联网查询能力，不限定为天气。只要信息适合从公开网络获得且不触及内部数据边界，都可以使用同一个工具查询。

以下问题允许调用 `web.search`：

- 天气、新闻、公开政策、法律法规、行业数据、公开市场信息；
- 公开企业信息、交通出行、赛事、汇率、节假日和其他时效性常识；
- 用户明确要求“联网查一下”“搜索公开资料”；
- 本地知识库没有答案且问题明显属于公开信息。

以下内容禁止联网：

- 项目、合同、供应商、人员等内部业务数据；
- Token、用户身份、租户、角色、权限、数据库结构；
- 上传附件原文、企业知识库原文和未公开业务数据；
- 包含系统字段、内部编号或疑似敏感内容的搜索词。

禁止联网时，系统应说明原因，并引导用户使用业务查询或知识库，不自动降级为公网搜索。

## 4. 统一工具协议

### 4.1 `system.current_time`

输入：

```json
{
  "timezone": "Asia/Shanghai"
}
```

`timezone` 可省略，默认使用 `agent.time-zone` 配置。

输出：

```json
{
  "date": "2026-09-11",
  "time": "14:30:00",
  "dateTime": "2026-09-11T14:30:00+08:00",
  "dayOfWeek": "星期五",
  "timezone": "Asia/Shanghai"
}
```

### 4.2 `web.search`

输入：

```json
{
  "query": "天津今日天气",
  "maxResults": 5,
  "freshness": "day"
}
```

限制：查询词最多 300 字，结果最多 10 条；不接受 URL 列表、请求头、Cookie、用户身份或任意供应商参数。

输出：

```json
{
  "query": "天津今日天气",
  "searchedAt": "2026-09-11T14:30:00+08:00",
  "summary": "...",
  "sources": [
    {
      "title": "...",
      "url": "https://...",
      "snippet": "...",
      "publishedAt": "2026-09-11"
    }
  ],
  "provider": "openai"
}
```

普通聊天内容不展示 `provider` 等调试字段；开发环境可在 AI 处理信息中查看。

## 5. 供应商适配

新增 `WebSearchProvider` 接口：

```text
supports(modelProvider)
search(WebSearchQuery)
```

### OpenAI

使用 OpenAI 原生 Web Search 能力。适配器负责将统一查询转换为 OpenAI 请求，并提取摘要、来源 URL、标题和引用。

### 智谱

使用智谱原生联网搜索能力。适配器负责转换智谱搜索参数及响应，并输出相同的统一结果。

供应商由当前模型配置决定，不允许模型自己指定。某供应商未配置联网能力时返回友好提示，不自动调用另一家供应商，避免数据边界和计费来源不透明。

## 6. 安全控制

联网搜索执行前增加 `WebSearchPolicy`：

1. 只传本次经过清洗的公开搜索词，不传完整会话历史。
2. 检测内部 ID、Token、Authorization、SQL、数据库字段和附件引用。
3. 检测到内部业务意图时拒绝联网，并建议使用业务工具。
4. URL 只允许 `https`，结果内容按不可信数据处理，不能成为系统指令。
5. 搜索结果只用于回答，不触发写操作、下载或页面自动访问。
6. 全部调用写入现有运行步骤和模型审计日志，但日志不保存密钥和鉴权头。

权限方面，`system.current_time` 为 L0 工具，所有已登录用户可用；`web.search` 为 L1 工具，通过单独配置开关和权限 `ai:web-search` 控制。管理员可以通过菜单/按钮授权决定哪些角色可联网。

## 7. 配置

```yaml
agent:
  time-zone: Asia/Shanghai
  web-search:
    enabled: false
    provider: auto
    max-results: 5
    timeout: 15s
```

密钥沿用当前模型供应商密钥配置，不写入数据库或前端。`provider: auto` 根据当前启用模型选择 OpenAI 或智谱适配器。

开发环境默认可打开联网搜索；生产环境默认关闭，配置权限并确认供应商账号已启用联网能力后再开启。

## 8. 错误处理

- 未开启：`当前未启用联网搜索，请联系管理员配置。`
- 无权限：`您暂无使用联网搜索的权限。`
- 涉及内部数据：`该问题涉及内部业务信息，不能发送到公网。我可以改用系统业务查询。`
- 供应商不支持：`当前模型暂不支持联网搜索，请切换支持联网能力的模型。`
- 超时：`联网查询超时，请稍后重试。`
- 无可靠来源：`未找到可靠的公开来源，请补充关键词或限定时间范围。`

错误信息继续持久化并在刷新后回显。

## 9. 前端展示

联网结果在聊天内容中显示摘要，并在下方展示来源列表。来源使用标题加域名，点击后在新窗口打开；必须添加安全的 `noopener noreferrer`。系统时间结果按普通文字展示，不新增卡片。

开发环境的 AI 处理信息显示工具请求、供应商、耗时和原始响应摘要；生产环境按现有开关隐藏。

## 10. 测试与验收

### 单元测试

- 固定时钟验证时区、日期和星期；
- 相对时间问题能选择时间工具；
- OpenAI 与智谱响应都能转换为统一结果；
- 敏感搜索词、内部 ID、Token 和业务问题被拒绝；
- 供应商超时和不支持场景返回中文提示；
- 工具名称兼容外部模型的字符限制。

### 集成测试

- 切换 OpenAI/智谱配置后由正确 Provider 执行；
- 联网结果包含来源并持久化；
- 刷新后工具处理信息和来源仍能回显；
- “当前时间”不发起网络请求；
- “查询今年立项项目”只调用时间和业务工具，不调用联网搜索；
- 内部权限范围不因联网工具发生变化。

## 11. 实施顺序

1. 实现 `system.current_time` 及相对时间提示规则。
2. 实现统一 `web.search` 协议和安全策略。
3. 实现 OpenAI Provider。
4. 实现智谱 Provider。
5. 接入工具注册、权限和系统提示。
6. 增加来源展示、持久化恢复及完整测试。
