# 本机连接 UAT 数据库时的业务地址修复

- 失败记录：利润排名 d8967abf-ff4e-4428-b7c4-5075b8a648f8；风险汇总 d4c775a2-de68-42a9-9d87-9546deefa13a。
- UAT 记录确认两次路由正确，均在工具执行阶段快速失败，无业务结果。
- 检查发现 application-dev.yml 将业务地址固定为 127.0.0.1:5084；本机 5084 连接被拒绝，8888 HTTP 返回 401（服务存在且需要认证）。用户截图也显示 smart-boot 在 8888 接收聊天。
- 修改 dev 业务地址为 ${SMART_BOOT_BASE_URL:http://127.0.0.1:8888}。数据库连接不变，使用 UAT 数据库不代表本机业务端口应使用部署端口。
- 若部署实例使用 5084，通过 SMART_BOOT_BASE_URL=http://127.0.0.1:5084 覆盖。本地已有该环境变量或启动参数时也须核对其值。
- 截图 TaskExecutor 是流式写出执行器配置警告，不能据此认定利润或风险 SQL 失败。
- 编译后由用户重启 smart-agent，分别重问利润排名和经营风险。未启动项目、未修改数据库，实际工具成功及数据准确性待验证。
