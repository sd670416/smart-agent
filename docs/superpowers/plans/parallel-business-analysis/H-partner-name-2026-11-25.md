# 合作方名称包含搜索

- 用户要求：输入“中天劳务”等部分名称时，先搜索，匹配多家再确认。
- 候选查询 mode=partners 改为数据库 LOCATE 参数化包含匹配，甲方、供应商均适用；百分号与下划线按名称字面匹配，不作为通配符。
- 仅从原有授权项目、菜单、租户及审批完成合同范围中查找候选，不扩大范围。
- 唯一候选按真实合作方 ID 查询原业务；多候选返回选择；没有候选保留空结果。明细与金额聚合不直接模糊匹配多家单位。
- 补齐 PARTNER_REFERENCE、PARTNER_TYPE 查询参数持久化，以支持选择后继续原查询。
- 名称参数与指令要求保留用户名称中的“劳务”“供应商”等文字，不擅自删词。
- 编译检查后待 UAT 验收，不启动服务、不修改数据库。
- 重启 smart-agent、smart-boot，前端无需更新。
- 测试：“和中天劳务合作的历史项目明细”；唯一候选返回完整单位名称的业务数据，多候选应先选择；选中后继续原明细查询。再测完整名称、无匹配名称及无权限账号，确认不会合并不同单位或扩大范围。
