# 项目报销比较实施与验收

日期：2026-10-21。状态：开发及自动回归完成，待人工验收。

## 实现范围

- 项目报销独立比较能力，支持同比、环比、自定义两组，不混入其他付款申请、普通付款申请或退款。
- 指标：报销单数、费用明细条数、当前范围报销金额；不是银行实际支付金额。
- 日期支持单据创建日期、报销日期、项目创建日期，两组必须明确同一日期维度及完整起止日，结束日包含全天。
- 一张报销单可能涉及多个项目，只统计当前权限且符合筛选的项目费用明细，单据去重计数。按项目创建日期比较是在选择项目明细，不等于报销发生期间。
- 沿用原报销查询审批完成、项目审批完成及排除项目状态1/3/10的限制；每组独立限制可信租户、项目报销菜单和当前可见项目范围。
- 同比上年同期；环比上一自然月、季度或年；完整期间对应完整上期，部分期间对应相应已过期间。自动比较禁止覆盖对比组，自定义比较明确两组。
- 日期含义或期间不明确先追问，同名项目分别确认两组；后续追问继承已确认条件并实时重新查询。结果交回模型组织中文业务答复，服务端计算差额和增长率；零基准不计算比例。

## 验证

- TDD失败回归：Agent未注册比较工具；Boot比较地址返回404而非预期权限拒绝。补实现后通过。
- Agent全量764项通过，无失败或错误。覆盖独立域注册、比较工具、签名、两组范围、自定义条件、日期及期间澄清、项目重名、后续实时查询及既有功能。
- Boot本轮38项通过：报销比较6、真实SQL8、报销控制器9、其他付款比较6及控制器9。
- SQL使用真实MyBatis映射、租户拦截器与H2。手算多项目单据：本组2单3条125.06元，对比组2单2条57.00元，差额68.06元；验证不累计主表9999元、不混入越权或未审批项目、跨租户明细。
- H2及模拟模型不能代替真实MySQL与页面端到端人工验收。未启动应用，未连接或修改业务数据库。
- 独立只读代码审查未发现需修复缺陷，覆盖三种比较、日期、跨项目明细权限、澄清恢复及实时上下文集成。
