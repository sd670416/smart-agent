# 材料退货退款独立智能查询

日期：2026-10-19。状态：已实现，自动化验证通过，待人工验收。

## 本批范围

- 独立查询材料退货退款单列表、材料明细、退货退款单数、明细条数和金额汇总。
- 智能助手工具 `materialRefund.query`，日期确认工具 `materialRefund.clarifyDate`。
- 沿用现有自然语言规划、实时工具调用、结果交回模型的链路；历史仅帮助定位项目、继承筛选及单据序号，不作为本轮事实。
- 不包含仅退货、公司仓、实际到账、付款合并、项目垫资利润或同比比较。

## 查询及日期

| 参数/能力 | 行为 |
| --- | --- |
| detail | 按匹配材料行分组为单据后分页，金额为当前条件下的本次退货退款小计 |
| items | 按真实requestId定位单据，重新查询其当前有权且匹配条件的材料明细 |
| summary | 全量去重主单数、材料明细条数及金额，不累加当前页 |
| returnDate | 材料明细退货时间；先筛明细再分组或统计，没有退货时间的行不计入区间 |
| createDate | 退货单创建时间 |
| projectCreateDate | 所属项目创建时间 |
| 日期不明确 | 先让用户确认；相对日期先调用当前时间工具；结束日全天包含 |
| 项目定位 | 编号/名称默认精确定位，同名追问；只有明确要求包含时才使用模糊匹配 |
| 序号追问 | 上次列表保存真实单据ID、单号和项目引用，不保留金额作为事实；当前权限收窄后过滤引用，仍须重新查询 |

缺少可见金额时拒绝返回不完整汇总，不悄悄当零；空项目范围返回空列表或零汇总。待办、已办、我发起等仍走审批查询。

业务答复使用中文列名，只称“退货退款金额”，不称“已到账退款”。内部字段与接口仅用于AI处理信息，不出现在业务答复中。
