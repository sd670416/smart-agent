# 工程产值单下钻实施与验收

日期：2026-10-22。状态：开发及自动验证完成，待人工验收。

## 范围

- 延续工程产值独立业务域，不转为待办或审批详情。
- 列表序号只定位上次结果的真实产值单ID，不用序号、单号或项目编号充当主键。
- `detail` 支持真实产值单ID精确查询主信息，补充施工合同金额、累计清单金额。
- `items` 必须指定真实产值单ID，返回工程名称、规格、单位、工程量、单价、金额、累计完成量及产值、应上报量及产值、本期完成量及产值。
- 每轮实时调用接口，再交给模型按中文列名回答。历史记录只用于理解项目、日期、单据定位和分页；指代不清先确认。
- 明细按排序值、明细ID稳定分页，最大每页100条；合计仍取主单全量聚合，不累加历史累计字段或分页明细替代总额。

## 权限与边界

- 项目菜单及当前可信可见项目范围；接口覆盖请求租户，服务显式过滤租户，主从表关联同时约束租户。
- 项目和产值单均审批完成且未删除，项目排除立项中、立项未通过、关闭。
- 工程量清单元数据只关联同租户、同项目的有效清单；异常关联不披露其他项目工程名称等资料，保留原产值明细金额。
- 比较请求携带产值单ID或工程量明细模式时拒绝，不能丢弃条件后扩大为整项目比较。
- 只读查询，不修改业务单据；本批不增加审批表单模板、劳务/专包产值、历史快照或其他来源单据下钻。
