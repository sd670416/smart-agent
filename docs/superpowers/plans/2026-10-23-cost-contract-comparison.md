# 五类成本合同自定义两组对比

日期：2026-10-23。状态：开发及自动验证完成，待人工验收。

## 已确认范围

- 比较材料、劳务、机械、专业分包、其他支出五类当前已审批合同的数量、合同金额与金额占比。
- 仅支持自定义两组；不支持同比、环比、历史快照或按合同发生日期比较。
- 日期仅按项目创建日期筛选项目，之后统计这些项目当前的合同。
- 每组使用全部五类来源作为占比分母，要求全部五类菜单权限，不能把无权来源当零。
- 服务端分别限制两组租户、可见项目；零分母占比不可计算，占比差额单位为百分点。
- 追问明细须先明确组别，保留所选组项目、合同名称与日期条件，每轮实时查询。
- 不启动应用、不改数据库、不提交、不切换分支；保留现有工作区改动。

- 比较甲项目和乙项目当前五类合同数量、金额及占比。

## 人工测试示例

将甲项目、乙项目替换为真实项目名称，日期范围可按实际数据调整：

1. “比较甲项目和乙项目当前五类成本合同的数量、合同金额和占比。”应分别列出两组及五类合同，不转到项目列表或施工合同。
2. 接着问“查看第二组材料合同明细”“下一页”。应只查询乙项目材料合同，保留第二组合同名称及日期等条件，不复用历史结果。
3. 新会话问“比较2026年1月创建的项目和2月创建的项目当前五类合同结构。”说明日期选择的是项目，金额是当前合同金额，不能称期间成本。
4. “比较这两个项目去年和今年的合同成本。”不能用当前数据冒充历史，应解释日期能力并确认；选择不限定日期后两组不再带旧日期。
5. 比较后问“查看材料合同明细”，如果上下文无法判断是哪一组，应先追问，不自行选组；缺比较对象、项目同名亦需确认。
6. 无任一类合同菜单权限账号尝试完整比较，应说明暂不能完整比较；范围外项目不得查询。对比两组总金额含零的情况，占比或增长率不可计算，不应显示0%。
