# 项目利润自定义两组当前数据比较

状态：开发及自动验证完成，待人工验收。沿用已确认利润公式与当前分支，不启动应用、不修改Web或数据库。

范围：新增 `projectProfit.compare` 和签名接口，支持 budget/actual/both 同指标的自定义两组当前累计比较。两组按真实项目、名称包含或项目创建范围选择，分别与可信租户和项目范围取交集；默认权限开启时按2/6/8来源校验，关闭时沿用业务只读授权。

金额及项目数量返回第一组、第二组、差额和增长率；第二组为零不可计算增长率，负基数保留并说明。利润率按各组全量合计计算，差额以百分点显示，不再计算利润率的增长率；任一利润率不可用时差值也不可用。预算利润=施工合同最终金额-合并预算，实际收支利润=收入-净付款，亏损保留、退款仅抵减一次。复用现有查询，不重新定义SQL公式。只支持项目创建范围后的当前数据，不支持历史快照或同比环比。
