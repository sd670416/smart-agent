# 施工进度智能查询实施记录

日期：2026-10-19

## 本批目标

将经营看板中的施工进度拆为项目域独立查询 `projectProgress.query`，支持项目汇总、项目分页和任务明细；不再调用看板接口。查询边界沿用项目菜单权限、可信租户和用户可见项目范围。

## 已完成

- Boot 新增施工进度请求模型、服务接口、MyBatis DAO、查询服务和内部工具控制器。
- Agent 新增施工进度工具、客户端和项目域路由贡献者。
- 非审批查询默认限定审批完成项目及施工计划，并排除项目状态 `1/3/10`。
- 根任务优先：项目存在审批完成且未删除的根任务时只取根任务；没有根任务时回退到该项目全部符合条件的任务。
- 日期支持项目创建日期，结束日按次日零点作为排他上界。
- Boot `mvn -pl smart-ai,smart-business/smart-project -am -DskipTests compile` 已通过。
- Agent `mvn test -DskipTests` 已通过编译阶段。

交互验收建议：

1. `查询施工进度`，再问 `第二个项目的任务明细`，应重新查询选中项目，不返回项目档案。
2. 针对已选项目问 `这个项目的任务明细`，应保留进度域；多个项目指代不明时先确认。
3. `查询2026年1月的施工进度`，应先确认日期含义；选择不限定日期后不保留1月范围。

5. 再问 `改查待办`，应实时调用审批查询，不带上施工进度的项目日期条件。

- 两个项目分别验证“有根任务”和“无根任务”的平均进度及任务明细。
- 验证审批状态、项目状态、删除状态、租户和可信项目范围隔离。
