# 施工合同按项目类型比较

日期：2026-10-23。范围已确认；开发及自动验证完成，待人工验收。

## 本批范围

- 扩展现有 `constructionContract.compare`，不新增看板域、接口、菜单或数据库字段。
- `current` 使用 `mode=summary, groupBy=projectType`。支持同比、环比和自定义两组；自定义两组必须使用相同分组及日期维度，不能一边分组、一边总计。
- 复用原合同分组查询，全量聚合后按真实项目类型编码对齐两期并集，不按分页截断，不累加当前页。空类型包含在“未分类”；未识别类型不丢弃，不将编码作为业务列展示。
- 每个类型返回合同数量、建设合同总金额、合同金额占比三项。数量和金额计算本期、对比期、差额及增长率；对比期为零时增长率为空并说明。
- 每期占比分母为该期完整筛选范围的最终合同金额，包含未分类；百分数保留4位小数。占比差额单位为百分点，不计算占比增长率；某期总金额为零时该期占比及两期占比差额为空，不伪装成0%。
- 某期没有该类型合同时，该期数量和金额按零比较，明确“仅本期有合同”或“仅对比期有合同”。这不表示项目类型是新创建的。两期均为空则返回无匹配数据，不编造字典中没有合同的类型。
- 返回真实的两期日期、项目及合同名称等条件。日期仍为项目创建、合同签订、合同创建三种维度；自动比较的日历期间规则不变，结束日包含全天，含义不明先确认。

## 权限与数据边界

- 沿用项目菜单权限、可信租户、当前可见项目交集。合同审批完成、未删除、登记类别1；项目审批完成、未删除，排除项目状态1/3/10。两组各自限制，空权限范围不读合同。
- 沿用当前项目类型及当前最终合同金额按所选日期筛选后的比较，不是历史时点类型或金额快照。不同自定义范围的占比以各自范围为分母，不能称同一总体的份额转移。
- 缺失匹配合同金额时拒绝不完整统计；不改原非分组比较、金额单位或日期公式。
- 逐轮实时调用接口，结果交模型用中文业务列回答。历史上下文仅用于条件及指代，不作为本轮事实或授权。

## 多轮追问

- 比较上下文额外保留去重的真实类型定位及服务端实际两期条件，不保存金额作为新一轮依据；特别保留自动推导的对比期日期。
- 查看某类型明细时先确定本期或对比期；无法唯一确定则追问，不默认选择一边。
- 改用 `constructionContract.query`、`detail`，清除分组并保留所选期的项目、合同名称、日期和真实类型过滤后重新查询。类型名称不明确时不猜编码、不清除过滤扩大范围。
