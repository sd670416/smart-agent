# 任务 6：解析器路由、异步摄取与清理

## 完成范围

- 使用 Apache Tika 根据实际字节检测文件类型，文件名仅用于识别可疑不匹配。
- 支持 PDF、DOCX、XLSX、Markdown、TXT 和常见图片；未知二进制标记为 `UNSUPPORTED`，可执行内容及危险不匹配标记为 `QUARANTINED`。
- 解析结果保留页码、工作表和章节位置，并限制源文件大小、Office 解压条目、解压体积、页数和提取字符数。
- XLSX 公式只保留公式文本，不执行公式；图片在未配置视觉模型时只提取元数据。
- 异步摄取复用现有分块、嵌入和向量索引接口，知识文档与聊天附件写入独立 Qdrant 集合。
- 向量载荷包含租户、空间、项目、文档、版本、发布状态、附件、过期时间和解析位置元数据。
- 过期聊天附件按有限页数处理，依次标记过期、删除临时向量、删除对象存储文件并记录清理完成时间；失败后可幂等重试。
- Flyway V7 为附件增加清理完成时间和清理查询索引。

## 验证结果

- 聚焦测试：12 项通过。
- Agent 全量单元测试：125 项通过，0 失败。
- MySQL 8.4.6 集成测试：4 项通过；Flyway V1-V7 从空库迁移成功，并验证 V7 字段和索引。
- 外部 Qdrant 集成测试：2 项通过；验证租户与授权范围、幂等重建和删除，以及知识/聊天附件双集合隔离。
- 外部测试创建随机临时集合，结束后自动删除，不使用生产集合。
