# 任务 5：知识管理与文档版本控制完成报告

## 交付范围

- 知识空间支持租户级和项目级范围，并持续校验管理权限、租户和项目访问权限。
- 知识文档采用独立版本记录，上传完成后进入 `PROCESSING`，仅解析成功转为 `DRAFT` 后允许发布。
- 发布时锁定文档，原子停用旧版本并更新活动版本；数据库约束附件唯一性和文档版本号唯一性。
- 重复完成同一附件保持幂等，历史小写状态及 `active` 空间状态在 V6 迁移中兼容。
- smart-boot 提供知识管理代理接口，管理使用独立的 `ai:knowledge:manage` 权限，上传策略使用 `ai:knowledge:upload` 权限，并安全映射下游错误。
- 可信上下文增加权限和可访问项目集合，字段经过排序后签名；Agent 兼容缺少新字段的旧令牌。
