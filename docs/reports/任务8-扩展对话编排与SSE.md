# Task 8：扩展对话编排与 SSE

## 完成内容

- Agent 提供授权对话流 `POST /agent/chat/stream`。
- 支持会话创建、运行查询、运行取消和重新生成新运行。
- SSE 事件按消息开始、状态、工具、引用、增量内容、消息结束顺序输出；引用在完成事件之前发送。
- 对话附件校验数量、所有权和 `READY` 状态，并将授权知识检索结果纳入对话上下文。
- Boot 通过 `/ai/chat/stream`、`/ai/conversations/**` 代理 Agent，并透传签名上下文和追踪信息。

## 验证结果

- Agent 全量测试：128 项通过。
- Boot `smart-ai` 全量测试：44 项通过（含新增聊天 SSE、会话查询和取消控制器测试）。
- `git diff --check` 通过。

## 已知边界

- SSE 控制器测试验证端点声明及代理行为；真实网络流式传输由客户端 WireMock 测试覆盖，未在单测中连接生产 Agent。
- 文件上传仍依赖前置 OSS 上传与附件完成接口；对话接口只接受已登记且状态为 `READY` 的附件。
- 任务不包含前端页面改造，也不包含 Task 9 的生产部署和性能压测。
